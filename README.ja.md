# ar-snow

https://code4fukui.github.io/ar-snow/

## 依存関係

- [three.js](https://threejs.org/)

## 機能

- 拡張現実（AR）または仮想現実（VR）で降る雪のパーティクルを表示
- WebXR APIを使用したAR/VRサポート
- クリッピングプレーンを実装し、スノードーム効果を作成
- ボタン操作でAR/VR体験の開始・停止が可能

## 使い方

プロジェクトを実行するには、ウェブブラウザで `index.html` または `hex.html` ファイルを開いてください。このプロジェクトは WebXR API を使用しているため、WebXR 対応のブラウザとデバイスが必要です。
